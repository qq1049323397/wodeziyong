# Versalone demo v1 assets

External raster assets for the RP-Hub character card
`维尔萨洛恩：啸风山脉纵切试玩版 V0.1`.

- `continent-map.webp`: clickable continent-map background.
- `howling-region-map.webp`: clickable Howling Mountains regional-map background.
- `fonts/`: UI-only Noto Sans SC and Noto Serif SC WOFF2 subsets.

The card stores only immutable HTTPS asset URLs and hotspot coordinates. It does
not embed either image in `chara`, and runtime AI-generated scene images remain
memory-only.

The Noto font subsets are served as external UI assets and retain the upstream
SIL Open Font License.
