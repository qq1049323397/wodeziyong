# River 214 opening assets

Public binary assets used by the shared RP-Hub opening regex.

- `v1/bgm.mp3`: background music
- `v1/scene-01.webp` through `scene-05.webp`: scene images
- `v1/manifest.json`: byte sizes and SHA-256 checksums

Shared cards use commit-pinned jsDelivr URLs. Do not rename or remove a published
version; add a new version directory for future updates.
